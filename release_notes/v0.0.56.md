# Vizor Wallet v0.0.56

This release introduces Ledger hardware wallet support on Windows, Linux,
and macOS. It also adds gift card usage tracking and improves voting and
wallet recovery.

## What's New

- Connect your Ledger to set up a wallet or add an account, and approve
  sends, shielding, swaps, payments, gift card funding, and voting on your
  device.
- Use Ledger over USB on all desktop platforms, or Bluetooth on macOS with
  supported devices.
- See whether gift cards you created are unused, have detected use, or are
  fully used, with clearer checking and confirmation statuses.

## Improvements

- Ledger account imports recover existing transparent transaction history
  and balances.
- Shield larger Ledger transparent balances through consecutive device
  approvals, with progress shown between transactions.
- Clearer voting progress and more reliable recovery of interrupted votes.
- Received gift cards now record their fiat value using the price at claim
  time when available.

## Fixes

- Fixed missing transparent funds received before the selected wallet
  birthday when importing an account.
- Improved recovery when inconsistent server responses interrupt wallet or
  gift card syncing.

## Notes

- Ledger support requires Zcash mainnet and Ledger Zcash app **3.9.3 or newer**.
- Bluetooth on macOS supports Ledger Nano X, Flex, and Stax. Windows and
  Linux support USB only.
- Linux users may need to install the Ledger USB permission rules included
  with the app.
- Moving recovered legacy Orchard funds into Ironwood is currently
  unavailable for Ledger accounts.
- Existing accounts affected by missing pre-birthday transparent funds may
  require re-importing to recover those balances.
