# Vizor Wallet v0.0.42

This release restores a more conservative ZIP 318 migration anchor window for
new Ironwood migrations and fixes a stuck migration transfer schedule.

## Improvements

- New Ironwood migrations again require at least one full ZIP 318 anchor bucket
  of age before proofs can proceed, instead of allowing the latest bucket.
  Existing migration schedules and already-persisted timing policies remain
  unchanged.

## Fixes

- Migration transfers that were already mined on-chain no longer stay stuck as
  **Due now** / **Sending now** and block later scheduled parts. Vizor now
  reconciles local confirmation state before picking the next due transfer.
