# Vizor Wallet v0.0.42

This release fixes stuck Ironwood migration transfer scheduling.

## Fixes

- Migration transfers that were already mined on-chain no longer stay stuck as
  **Due now** / **Sending now** and block later scheduled parts. Vizor now
  reconciles local confirmation state before picking the next due transfer.
- When lightwalletd accepts a migration transfer but local wallet storage
  fails, the part is marked submitted (`broadcasted`) instead of left
  `scheduled`, so later parts are not head-of-line blocked while storage is
  retried.
