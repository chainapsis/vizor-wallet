# Vizor Wallet v0.0.63

Vizor is ready for the Zcash NU7 network upgrade, expected around
November 5, 2026 (UTC), at mainnet block height 3,543,405. Once the
network reaches that height, Vizor will automatically switch to NU7.

## What's New

- Ledger accounts can now move Orchard funds to Ironwood using
  Immediate migration.

## Notes

- Ledger users: before NU7 activates, use Ledger Wallet to update
  your device firmware and install Zcash app version 3.10.0 or newer.
- Some transaction actions may pause briefly around activation.
  If an ongoing Ironwood migration is stopped by the upgrade,
  Vizor shows what remains and guides you through moving the rest.
