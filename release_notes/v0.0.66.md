# Vizor Wallet v0.0.66

This release improves hardware wallet voting, swap deposit tracking, and
transaction details, with clearer address previews.

## Improvements

- Added Zcash Labs mainnet servers to network settings and automatic server
  selection.
- Improved Keystone signing QR readability and added an enlarged QR view when
  approving votes.
- Home and Activity now explain when transaction details are being checked
  privately, why checking stopped, and when amounts may still change.
- Improved address previews across Send, Receive, Swap, Pay, and Contacts so
  shortened addresses are easier to check.
- Confidential swaps and payments now explain why NEAR Intents explorer links
  are unavailable.
- Improved voting preparation on slow connections to reduce premature timeouts.

## Fixes

- Fixed Ledger voting getting stuck after a device rejects an eligible saved
  signing request. Vizor can rebuild the request for you to review and approve
  again.
- Fixed swap progress advancing before a deposit was detected and deposit
  status submission errors appearing as payment failures. Expired swaps now
  recheck their status when opened and provide clearer guidance for undetected
  or late deposits.
- Fixed already-received gift cards being checked again. Vizor now identifies
  the account that received the card.
- Fixed the sidebar balance differing from the balance shown on Home.
