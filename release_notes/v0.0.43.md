# Vizor Wallet v0.0.43

This release helps large Ironwood migrations finish sooner, strengthens
recovery for expired migration transfers, and makes switching between accounts
faster and more reliable.

## If a Migration Is Already in Progress

- Updating does not interrupt an existing migration. After updating, unlock
  Vizor and your migration will resume from its saved progress and schedule.
- Existing migration schedules and saved timing policies remain unchanged.
  The updated proof timing applies only to newly started migrations.
- You can update now or let your current migration finish first. No action is
  required if the migration is progressing as expected.
- If you want to change course, you can now stop the remaining scheduled
  transfers and restart the migration from the home page. Transfers already
  submitted to the network cannot be reverted.

## Improvements

- New Ironwood migrations with many preparation or transfer steps now use
  shorter randomized spacing, helping large migrations complete sooner.
- Previously viewed accounts now show their last known balance and activity
  immediately when you switch back, while Vizor refreshes them in the
  background.
- Improved balance and activity refresh performance, especially for wallets
  with multiple accounts.
- Reduced background migration status work to keep multi-account wallets more
  responsive.

## Fixes

- Improved recovery for expired migration transfers so rebuilt transfers keep
  a coordinated schedule based on current progress instead of being delayed by
  the original schedule again.
- Fixed multi-part migration recoveries that could fail, overlap schedules, or
  leave later transfers waiting much longer than intended.
- Fixed stale balances potentially remaining visible or reappearing after an
  account switch when a fresh balance is temporarily unavailable.
