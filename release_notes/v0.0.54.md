# Vizor Wallet v0.0.54

This release adds custom transaction explorers and visible vote-share delivery
progress, while improving Tor startup, Keystone signing privacy, and wallet
performance.

## What's New

- Added transaction explorer selection under Settings. CipherScan remains the
  default, or you can use another explorer or a custom URL template.
- Vote details now show encrypted share submission progress, including the
  number submitted and an estimated completion time while voting remains open.

## Improvements

- Keystone-backed sends and ZEC swap deposits now use compact batch signing,
  reducing the transaction data shared with the device and the size of return
  QR codes.
- Reduced sync and mempool processing delays for wallets with large transaction
  histories.
- Improved encrypted vote-share delivery and recovery across helper failures,
  wallet locks, and account changes.
- Home-screen ZEC totals now use a cleaner 4–5 decimal-place display.
- Temporary swap status refresh failures are now presented as automatic retry
  states instead of alarming transaction failures.

## Fixes

- Fixed startup requests failing while Tor was still connecting. Vizor now
  waits for Tor and shows clearer connection status and recovery guidance.
