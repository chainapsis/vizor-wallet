# Vizor Wallet v0.0.53

This release adds contact autocomplete and faster transaction preparation,
improves voting and historical sync reliability, and allows users to send funds
before the Ironwood migration is performed.

## What's New

- The send recipient field now suggests matching Zcash contacts as you type,
  with names, profile pictures, and address previews.

## Improvements

- The send screen now prepares transaction proofs in the background, reducing
  the delay when confirming the first send.
- Sending funds is now allowed before the Ironwood migration is performed.
- Active voting rounds now prepare privacy proofs in the background, reducing
  the wait when casting a vote.
- Voting submissions now prioritize responsive helper services and continue
  remaining delivery safely in the background.
- Historical wallet sync now uses optimized batch sizes around unusually
  intensive block ranges, improving recovery performance without increasing
  memory pressure.

## Fixes

- Voting now waits for confirmation of the required immediate share before
  reporting submission as complete.
- Voting submissions no longer remain stuck finalizing when a round ends before
  confirmation arrives. Vizor performs a final check and provides recovery
  guidance when necessary.
