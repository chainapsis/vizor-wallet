# Vizor Wallet v0.0.44

This release makes large Ironwood migrations faster and more reliable,
improves Keystone signing and QR guidance, and makes account recovery
information easier to access.

## If a Migration Is Already in Progress

- Updating does not interrupt an existing migration. After updating, unlock
  Vizor and your migration will resume from its saved progress and schedule.
- Existing migration schedules and saved timing policies remain unchanged.
  The updated proof timing applies only to newly started migrations.
- You can update now or let your current migration finish first. No action is
  required if the migration is progressing as expected.
- If you want to change course, you can now stop the remaining scheduled
  transfers and restart the migration from the home page. Transfers already
  submitted to the network cannot be reverted.

## What's New

- You can now open the secret phrase for any software account directly from
  its account menu, without switching accounts first.
- Added guidance beside Keystone signing QR codes to help resolve scanning
  issues and find the latest Keystone firmware.

## Improvements

- Improved planning for large Ironwood migrations so complex balances can be
  split into affordable transfers more reliably.
- Balance and migration status updates are now faster, especially for wallets
  with multiple accounts or many migration steps.
- Scheduled migration transfers now advance more promptly when they become
  due.
- Stopping a migration now returns to the app sooner after the remaining
  schedule has been cancelled.
- Large balances in the sidebar now use compact labels for easier reading.

## Fixes

- Fixed Keystone migrations with multiple signing batches so later batches
  continue correctly and larger groups of transfers can be signed together.
- Fixed navigation after completing or leaving a Keystone send.
- Fixed Pay availability during an Ironwood migration so it appears when
  Ironwood funds are available and stays hidden when they are not.
- Fixed Orchard balances during migration and clarified when migrated funds
  are waiting for network confirmation.
