# Vizor Wallet v0.0.45

This release adds BIP39 passphrase support and improves the reliability,
timing, and visibility of Ironwood migrations and Keystone signing.

## If a Migration Is Already in Progress

- Updating does not interrupt an existing migration. After updating, unlock
  Vizor and your migration will resume from its saved progress.
- If no scheduled transfer has been submitted yet, Vizor may shift the pending
  transfer schedule forward when proof finalization becomes available. This
  preserves the approved spacing instead of clustering transfers together.
- You can update now or let your current migration finish first. No action is
  required if the migration is progressing as expected.
- If you want to change course, you can stop the remaining scheduled transfers
  and restart the migration from the home page. Transfers already submitted to
  the network cannot be reverted.

## What's New

- You can now import wallets protected by an optional BIP39 passphrase.
- Keystone migration signing now shows the exact number of QR signing rounds
  and transactions before scanning begins.

## Improvements

- Improved initial Ironwood migration scheduling so transfer spacing begins
  when proofs can actually be finalized, avoiding tightly clustered early
  transfers.
- Large Keystone migration signing requests are now divided into device-safe
  QR rounds based on their encoded size.

## Fixes

- Fixed an issue that could prevent a finalized Keystone migration transfer
  from being submitted while a later transfer was still waiting for its proof
  window.
- Truncated synchronization errors in the desktop sidebar can now be read in
  full by hovering over them.
