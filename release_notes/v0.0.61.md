# Vizor Wallet v0.0.61

This release adds viewing key export options, improves Ledger connectivity
and signing, and strengthens wallet privacy and reliability.

## What's New

- Export an incoming or full viewing key as a QR code or text, with
  explanations of what each key reveals.
- Share your address directly from Receive, with clearer Copy, Share, and
  Request ZEC actions.

## Improvements

- Ledger setup and signing provide clearer step-by-step guidance, including
  recovery after a declined request and an explanation of the wait before
  device approval.
- Improved recovery instructions for Ledger USB errors, invalid Bluetooth
  pairings, and restricted Bluetooth access.
- Ledger Send generates transaction proofs while you review on the device,
  reducing waiting and reusing completed work when retrying.
- Transaction details load faster, with less time spent showing loading
  placeholders.
- Improved Private queries privacy by reducing response-dependent request
  patterns and handling failed responses more reliably.
- Pending shielding transactions show progress and confirmation estimates in
  Activity.
- Added the Stardust Korea server. Saved selections for retired Stardust
  servers now use the default server.

## Fixes

- Fixed Ledger Bluetooth setup getting stuck after device selection on macOS,
  and improved reconnection when retrying.
- Fixed unavailable Close actions in Ledger Bluetooth recovery screens when
  access is restricted.
- Fixed Linux wallets appearing missing after restart when using a
  passwordless GNOME keyring.
- Improved recovery of interrupted Ledger and Keystone shielding.
- Sensitive content hidden by the privacy shield is also hidden from screen
  readers.
- Expanded masking of recognizable addresses, keys, transaction identifiers,
  and other sensitive identifiers in app logs.
- Strengthened certificate validation for sync, Private queries, and Tor
  connections.

## Notes

- Private queries remain experimental and mainnet-only. Recovery may progress
  over several blocks without automatically falling back to public lookups.
- This update changes wallet database and Linux keyring storage formats.
  Downgrading after the update is unsupported.
- Linux users whose keyring data was already lost may need their secret
  passphrase to restore their wallet.
