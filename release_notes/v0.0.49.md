# Vizor Wallet v0.0.49

This release streamlines Keystone voting with batched approvals and clearer
bundle details, improves voting recovery, and strengthens reliability on
Windows.

## If a Migration Is Already in Progress

- Updating does not interrupt an existing migration. After updating, unlock
  Vizor and your migration will resume from its saved progress and schedule.
- Existing migration schedules and saved timing policies remain unchanged.
  The updated proof timing applies only to newly started migrations.
- You can update now or let your current migration finish first. No action is
  required if the migration is progressing as expected.
- If you want to change course, you can now stop the remaining scheduled
  transfers and restart the migration from the home page. Transfers already
  submitted to the network cannot be reverted.

## Improvements

- Keystone can now sign multiple voting bundles with one approval, reducing the
  number of QR signing rounds required.
- Keystone voting now shows the memo for each bundle in a signing batch, with
  controls for reviewing them individually.
- Previously saved Keystone voting signatures are restored after an
  interruption or restart, so completed signing work does not need to be
  repeated.
- The Windows camera preview is now mirrored for a more natural scanning
  experience.

## Fixes

- Windows now prevents multiple copies of Vizor from accessing the same wallet
  at once. Opening Vizor again restores or brings the existing window forward.
- Improved secure storage reliability on Windows so wallet settings are written
  safely if an update is interrupted.
