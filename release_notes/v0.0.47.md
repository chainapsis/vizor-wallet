# Vizor Wallet v0.0.47

This release brings Tor to Vizor desktop, extending network privacy across
wallet activity, in-app services, and supported software updates. Tor is
optional and can be enabled before wallet setup or at any time from Settings.

## If a Migration Is Already in Progress

- Updating does not interrupt an existing migration. After updating, unlock
  Vizor and your migration will resume from its saved progress and schedule.
- Existing migration schedules and saved timing policies remain unchanged.
  The updated proof timing applies only to newly started migrations.
- You can update now or let your current migration finish first. No action is
  required if the migration is progressing as expected.
- If you want to change course, you can now stop the remaining scheduled
  transfers and restart the migration from the home page. Transfers already
  submitted to the network cannot be reverted.

## What's New

- Enable Tor before creating or importing a wallet from Network settings, or
  later from Settings > Privacy.
- When Tor is enabled, Vizor routes wallet synchronization, transaction
  broadcasts, in-app services, and supported software-update traffic through
  Tor.
- Added Tor support for macOS and Windows software updates, Wallet Link, and
  custom onion lightwalletd endpoints.
- Tor connections use fail-closed protection, keeping direct requests blocked
  while Tor is connecting or if the connection fails.

## Improvements

- Added clear Tor connection status, transition progress, and recovery actions.
- Independent transaction broadcasts use separate Tor circuits to reduce
  linkability between wallet activity.
- Windows users can choose whether to download an update through Tor or switch
  to a direct connection first.
- Added Pay to the desktop sidebar.
- Software and Keystone wallet imports now let you choose an account name and
  profile picture.
- Refreshed Secret Passphrase entry and display, and added the ability to clear
  an existing BIP39 passphrase during import.

## Notes

- Links opened in another application do not use Vizor’s Tor connection.
- On Linux, Vizor checks for updates through Tor, but release pages and
  downloads opened in your browser use the browser’s own connection.
- Some third-party services may reject Tor connections. Vizor will explain when
  this affects Pay or Swap and provide guidance for continuing.
