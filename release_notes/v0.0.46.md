# Vizor Wallet v0.0.46

This release keeps scheduled Ironwood migration transfers running reliably
while Vizor is hidden and improves recovery after sleep or long inactivity.

## If a Migration Is Already in Progress

- Updating does not interrupt an existing migration. After updating, unlock
  Vizor and your migration will resume from its saved progress and schedule.
- Existing migration schedules and saved timing policies remain unchanged.
  The updated proof timing applies only to newly started migrations.
- You can update now or let your current migration finish first. No action is
  required if the migration is progressing as expected.
- If you want to change course, you can now stop the remaining scheduled
  transfers and restart the migration from the home page. Transfers already
  submitted to the network cannot be reverted.

## Improvements

- Scheduled migration transfers now continue on desktop while Vizor's window is
  minimized or hidden.
- Vizor now safely refreshes overdue migration state after sleep, suspension,
  or a long lock while preserving the intended gaps between remaining
  transfers.

## Fixes

- Fixed an issue that could leave scheduled migration transfers waiting while
  Vizor was minimized or hidden.
- Prevented macOS App Nap from delaying scheduled migration work while Vizor is
  hidden.
