# Vizor Wallet v0.0.48

This release adds viewing key export and improves Pay recipients, ZEC price
availability, wallet imports, Tor controls, and Keystone QR scanning.

## If a Migration Is Already in Progress

- Updating does not interrupt an existing migration. After updating, unlock
  Vizor and your migration will resume from its saved progress and schedule.
- Existing migration schedules and saved timing policies remain unchanged.
  The updated proof timing applies only to newly started migrations.
- You can update now or let your current migration finish first. No action is
  required if the migration is progressing as expected.
- If you want to change course, you can now stop the remaining scheduled
  transfers and restart the migration from the home page. Transfers already
  submitted to the network cannot be reverted.

## What's New

- Export the Unified Full Viewing Key for any software or Keystone account
  from Settings or the account menu after confirming your wallet password. A
  viewing key provides read-only access to balances and transaction activity
  and cannot be used to spend funds. Keep it private and share it only with
  people or services you trust.

## Improvements

- Improved Pay’s Recently sent list so saved contact identities remain
  accurate, contacts sharing an address remain distinct, and recently
  broadcast payments appear promptly.
- Vizor can now show recently fetched ZEC market data immediately after a
  restart or during a temporary network failure. Cached prices expire after
  one hour.
- Wallet birthday lookup is now faster when importing a mainnet wallet.
- You can stop a pending Tor connection from Settings and return to a direct
  connection without restarting Vizor.

## Fixes

- Fixed a Keystone QR scanning issue that could occur when the scanning-help
  overlay disappeared as the QR state changed.
