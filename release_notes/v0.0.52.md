# Vizor Wallet v0.0.52

This release makes coinholder voting faster and more resilient, adds TEX
payment support for Keystone hardware wallets, and improves recovery from
interrupted voting and hardware-wallet sends.

## What's New

- Keystone hardware wallets can now send to TEX addresses using a guided
  two-transaction QR signing flow.

## Improvements

- Coinholder voting now performs independent proof work in parallel, reducing
  the time needed to delegate voting power and submit votes.
- Voting can now switch between compatible privacy-preserving query services
  and prioritize responsive helper servers when a service is slow or
  unavailable.
- Completed votes now leave the finalizing screen sooner while remaining
  confirmation work continues safely in the background.

## Fixes

- Improved recovery when a voting transaction was submitted but its status
  could not be confirmed, with clearer guidance and fewer conflicting retries.
- Hardware-wallet sends now handle partial or uncertain broadcasts more safely
  and avoid suggesting another send when a transaction may already be on the
  network.
- Voting options remain available while voting power is still loading.
