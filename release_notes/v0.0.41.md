# Vizor Wallet v0.0.41

This release reduces average waiting times for new Ironwood migrations.

## If a Migration Is Already in Progress

- We adjusted the ZIP 318 timing parameters so newly started migrations can
  prepare and transfer funds more quickly on average.
- Updating does not interrupt an existing migration. After updating, unlock
  Vizor and your migration will resume from its saved progress and schedule.
- You can skip this update while your current migration finishes. However, we
  recommend updating before starting another migration so it can use the
  shorter timing parameters.
- Vizor does not currently provide an option to cancel a migration. If you want
  to restart using the shorter schedule, you can remove and re-import the
  migrating account, wait for it to sync, and then begin the migration again.
  Only do this after confirming that you have everything needed to recover the
  account.

## Improvements

- New Ironwood migrations now use shorter preparation and staged-transfer
  intervals, reducing average waiting times. Existing migration schedules
  remain unchanged.

## What's New

- New software accounts now start with a suggested name and profile picture
  that you can review or change before finishing setup.
