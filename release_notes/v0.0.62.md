# Vizor Wallet v0.0.62

This release adds private query server selection and request-link pasting,
speeds up wallet and activity loading, and improves sending reliability.

## What's New

- Choose a Private queries server in Settings, compare response times,
  or enter a custom HTTPS server.
- Paste a Zcash request link into Send to review its payment details.
  Address-only links fill in the recipient address directly.

## Improvements

- Faster startup and unlocking, with saved balances displayed while
  the wallet syncs.
- Gift cards show saved information first, with status checks continuing
  in the background.
- Activity loads progressively as you scroll and preserves existing rows
  and your position during refreshes.
- Sending can proceed once scanning and balance checks finish, while
  transaction history continues loading.
- Scanning the original payment QR now shows whether its address,
  amount, and memo match the incoming request link.

## Fixes

- Fixed payment requests continuing to report insufficient funds after
  more funds become available.
- Fixed Max sends being rejected when the displayed balance lagged
  behind the available amount.
- Applied certificate-validation and TLS security fixes.

## Notes

- Private queries remain experimental and mainnet-only. Servers are
  not switched automatically; if a listed server is removed, choose
  a replacement in Settings.
